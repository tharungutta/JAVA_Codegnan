## 🌟 About This Repository

Welcome to **JAVA_Codegnan**! This repository is a collection of Java code examples created while learning and practicing Java programming.

The goal is to make Java easier to understand by keeping practical code examples for different concepts in one place. Instead of learning only from theory, you can explore the source code, run programs, change the inputs, and observe the output to understand how each concept works.

Whether you are starting with Java or revising concepts for assignments, coding practice, interviews, or Java Full Stack preparation, this repository can serve as a reference for your learning journey.

> **What you will find here:** Java programs for concepts covered in the repository, with examples you can read, run, modify, and practise. The exact topics available depend on the Java files committed to the repository.

## 🎯 Objectives

## 🚀 Getting Started

### Prerequisites

Install the following before running the programs:

- **JDK (Java Development Kit):** Install a suitable JDK version.
- **Code editor or IDE:** IntelliJ IDEA, Eclipse, or Visual Studio Code with Java support.
- **Terminal:** Command Prompt, PowerShell, or a terminal built into your IDE.

Verify your Java installation:

```bash
java -version
javac -version
```

Both commands should display version information.

### 1. Clone the repository

```bash
git clone https://github.com/tharungutta/JAVA_Codegnan.git
```

### 2. Open the project folder

```bash
cd JAVA_Codegnan
```

### 3. Find a Java program

Browse the folders and choose the `.java` file for the concept you want to practise.

### 4. Compile the program

For a Java file without a package declaration, run:

```bash
javac FileName.java
```

Replace `FileName.java` with the actual filename.

### 5. Run the program

```bash
java FileName
```

Use the class name without the `.java` extension. The class containing the entry point should have:

```java
public static void main(String[] args)
```

**For programs inside packages:** compile and run them from the correct project root using the package-qualified class name. Follow your IDE's project configuration if one is provided.

## 💡 How to Learn from Each Program

1. **Read the code:** Identify the concept demonstrated.
2. **Predict the output:** Try to understand what the program will print.
3. **Run it:** Compile and execute the program.
4. **Experiment:** Change input values and test different cases.
5. **Improve it:** Try rewriting the solution or handling additional cases.
6. **Revise:** Explain the concept in your own words.

Active practice is one of the best ways to build confidence in Java.

## 🧪 Example: A Simple Java Program

```java
public class HelloJava {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

Compile and run:

```bash
javac HelloJava.java
java HelloJava
```

Output:

```text
Hello, Java!
```

This simple program demonstrates a class, the `main` method, and console output.
